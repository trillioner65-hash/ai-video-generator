# AI Video Generator

A full-stack AI video generation starter with:
- FastAPI backend
- React + Vite frontend
- user authentication and accounts
- SQLite-backed video history and job tracking
- async background worker queue
- mock generation fallback for local dev
- optional Replicate real generation
- Docker and deployment configuration

## Overview

This project is designed to feel like a real AI video SaaS:
- users create accounts and log in
- users submit prompts to generate videos
- jobs run in the background
- finished videos are saved and shown in the gallery
- users can download their own generated videos

## Tech stack

- Backend: FastAPI + SQLAlchemy + SQLite
- Auth: JWT with bcrypt password hashing
- Frontend: React + Vite
- Workers: background thread queue process
- Mock generation: ffmpeg
- Real generation: Replicate API

## Quick start

### 1) Backend

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app:app --reload
```

### 2) Frontend

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

Open:
- Frontend: http://localhost:5173
- API: http://localhost:8000

## Environment config

```env
JWT_SECRET_KEY=change-me
DATABASE_URL=sqlite:///./app.db
REPLICATE_API_TOKEN=
VIDEO_MODEL=genmo/mochi-1-preview
```

## Auth and account features

- register via `/api/register`
- login via `/api/login`
- fetch current profile via `/api/me`
- each user sees only their own generated videos and jobs

## API

### Register

```bash
curl -X POST http://localhost:8000/api/register \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo","email":"demo@example.com","password":"secret123"}'
```

### Login

```bash
curl -X POST http://localhost:8000/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"demo","password":"secret123"}'
```

### Create a video job

```bash
curl -X POST http://localhost:8000/api/jobs \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "a cinematic neon city at night",
    "duration": 5,
    "aspect_ratio": "16:9",
    "provider": "mock"
  }'
```

### Video gallery

```bash
curl http://localhost:8000/api/videos \
  -H 'Authorization: Bearer <token>'
```

## Mock mode requirements

The mock generator uses ffmpeg, so install it first:

- macOS: `brew install ffmpeg`
- Ubuntu/Debian: `sudo apt install ffmpeg`
- Windows: install from https://www.ffmpeg.org/download.html

## Notes

This project is suitable as a strong starter for a real AI video SaaS, but production deployments should also include:
- external Redis/RQ or Celery for stronger job orchestration
- object storage (S3/R2)
- Kubernetes or a managed app platform
- rate limiting and moderation
- multi-user admin controls
- CI/CD and proper secrets management
